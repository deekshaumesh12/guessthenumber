Number Guessing Game
A fun, interactive number guessing game built with HTML, CSS, and JavaScript. contains a beautiful UI(basically what i could do) with interactive animated blocks and a clean, responsive design.

What can you do?

Interactive Gameplay — Guess a number between 1-100
Animated UI — Black and white alternating blocks with hover effects
Responsive Design(i tried my best) — Works on desktop and mobile devices
Smooth Animations(hope it works) — Parallax scrolling effect on GUESS blocks
Real-time Feedback(it's fast like that) — Get instant feedback (GUESS HIGHER/GUESS LOWER)

How to play?-very easy(did it for timepass)

Enter a number between 1 and 100
Click "Submit" or press Enter
Read the feedback: "GUESS HIGHER" or "GUESS LOWER"
Keep guessing until you get it right
Click "Reset Game" to play again

have fun playing this timepass game if you're ever bored(tried to go with the wordle kind aesthetic, hope you enjoy!)
