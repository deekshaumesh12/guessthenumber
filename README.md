# Number Guessing Game

A fun, interactive number guessing game built with HTML, CSS, and JavaScript. Features a beautiful UI with interactive animated blocks and a clean, responsive design.

## Features

- 🎮 **Interactive Gameplay** — Guess a number between 1-100
- 🎨 **Animated UI** — Black and white alternating blocks with hover effects
- 📱 **Responsive Design** — Works on desktop and mobile devices
- ✨ **Smooth Animations** — Parallax scrolling effect on GUESS blocks
- 🎯 **Real-time Feedback** — Get instant feedback (GUESS HIGHER/GUESS LOWER)

## How to Play

1. Open `index.html` in your web browser
2. Enter a number between 1 and 100
3. Click "Submit" or press Enter
4. Read the feedback: "GUESS HIGHER" or "GUESS LOWER"
5. Keep guessing until you get it right!
6. Click "Reset Game" to play again
